# Agent Runtime 交互教程：内容与交互设计

本网站为源码技术分享与课后阅读服务。主要材料为 notes_optimized.md，源码统一引用 v0.24.0 / 17d994bd3045dae71acda676a4ef4762ed8ecd94。源码片段通过 git show 从固定提交提取，不采用带有学习改动的工作区行号。

## 主线与页面

以“明天上海适合户外运动吗？”建立问题，再用已有实验中的 Tokyo 固定天气演示执行循环；明确这两个案例的角色与数据差异。

九个学习章节按序为：为什么需要 Runtime、天气请求逐步演示、Runner 源码路径、模型调用与响应、FunctionTool、NextStep 与交接、生命周期与扩展点、预测与实验、设计取舍。每章保留来源与理解测验；附术语索引、复习卡和资料页。

章节组织沿笔记第一至三章展开，再把工具、控制流和扩展点接回天气循环。笔记中后半部分的 Session / RunState、Guardrails / Streaming / Tracing 作为主线关联知识和进一步阅读，不把所有 SDK 功能平铺成同等篇幅。

交互包括：可回退/重置的天气步骤演示；公开入口到循环的源码位置选择；JSON 参数在预设场景下的执行模拟；四种 NextStep 选择；模型与工具生命周期时间线；先猜后查看既有实验输出；有解析的测验、复习卡和本机阅读进度。投屏模式扩大字号、收起侧栏，保留章节与退出按钮。支持键盘、窄屏、减少动态效果和打印。

## 内容边界

- 笔记第 4 章只写到装饰器入口；第 5 章已由用户在制作期间补充，纳入最新 Handoff 调用链。网站补充部分按“新增 · 源码核对”标记，不推断作者已完成全部边界的逐行研究。
- 笔记第 8 章是使用真实模型 API 的实验设计与预期；网站展示的是现有 ScriptedModel 实验的保存日志，明确两者不同。
- 审批恢复、stop_on_first_tool、并行失败/取消等没有现有实验结果的项目保持待验证。交互图只表达简化控制流。
- 原注释把恢复路径中的 handoff 描述为“不消耗轮次”，这个表述不能扩展到普通新模型轮次。普通新轮次在调用模型前计数，handoff 后的目标模型调用受同一个 max_turns 约束。
- AgentRunner 内部类不属于公开 API；讲解可阅读内部实现，业务侧使用 Runner。
- hooks 用于生命周期回调；输入改写优先讲明确的 call_model_input_filter 扩展点。非流式 llm_end 在此版本有延迟调用/恢复处理，不能把它固定画成 HTTP 返回后一行的所有路径保证。
- LangGraph 对比只保留笔记里的抽象层次分析，不声称逐项做过同版本功能验证。

## 实现与交付

原生 HTML/CSS/JavaScript，内容、固定源码片段和界面逻辑分别保存；静态数据本地加载，不需要模型密钥、网络字体或 CDN。index.html 可直接打开，支持静态 HTTP 服务。遵循 knowledge-site-creator 的黄色主题、学习/测试/索引/进度思路，按本次需求简化默认页面数量。暂不加入 Service Worker，避免审阅期间刷新仍命中旧页面；不自动部署、不添加未经核实的站点域名/SEO身份。

依赖仅用于 Cloud IDE 中浏览器验收；网站本身零依赖、无需构建。保护现有源码、笔记及未提交修改。验收覆盖核心交互、来源链接生成、资料下载、手机与投屏布局、刷新进度和控制台错误。实际证据与限制单独记录在 QA.md。
